# Bundled typography

Fredoka, Nunito, Patrick Hand and VT323 are self-hosted here so visitors do not need an external font-service request. Each family includes its original SIL Open Font License in `OFL.txt`.

Source: https://github.com/google/fonts/tree/main/ofl (downloaded 2026-11-01).

- `fredoka/font.ttf`: Fredoka variable width/weight font.
- `nunito/font.ttf`: Nunito variable weight font.
- `patrickhand/font.ttf`: Patrick Hand Regular.
- `vt323/font.ttf`: VT323 Regular.

No font files were modified. The fonts are used for visual presentation; controls retain a readable body face even when pixel or handwritten headings are selected.
